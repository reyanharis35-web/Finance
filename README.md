# Weekly Budget

Tells you how much you can spend each week after your fixed costs.

1. Enter your monthly take-home income.
2. Add your fixed expenses (rent, bills, subscriptions). Pick how often each one is paid; yearly and weekly costs are converted to monthly.
3. Optionally set an amount to save each month.

It shows **(income − fixed expenses − savings) × 12 ÷ 52** per week. A month is about 4.33 weeks, not 4, so dividing by 4 would overstate your weekly money.

## Use it
Open `index.html` in any browser. No login, no server, no install.

Your data is saved in that browser only. Use **Download backup** now and then; clearing site data erases it.
